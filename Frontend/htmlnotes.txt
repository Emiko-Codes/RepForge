     HEAD:
In an HTML document, the <head> section contains information about the webpage, not the visible content.
Everything inside <head> helps the browser, search engines, and other tools understand the page, but it does not appear on the screen.

Basic Structure:
<!DOCTYPE html>
<html>
<head>
    <!-- information about the page -->
</head>

<body>
    <!-- visible content -->
</body>
</html>

The 5 Most Important Things Inside <head>:

1 -                              <title> (VERY IMPORTANT)
This is the text shown in the browser tab.
<head>
    <title>Workout Tracker</title>
</head>

What you see in the tab:
Workout Tracker | Chrome

This is also what shows up as the main title in Google search results.



2-     <meta>

In HTML, the <meta> tag provides metadata about the webpage.

Metadata = information about the page, not content that the user sees.
It goes inside the <head> section and helps browsers, search engines, and other tools understand your page.

 <meta> always goes inside the <head> section.
        
Common <meta> tags you should know:

1- Character Encoding

<meta charset="UTF-8">
This tells the browser how text characters are encoded.
UTF-8 supports:
    letters
    emojis
    international characters
Almost every modern site includes this.



2- Viewport

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Without it:
your site looks zoomed out on phones
With it:
the page fits the screen properly



3 -  Page description

<meta name="description" content="Track workouts, sets, and reps easily.">
Search engines like Google use this as the page preview description. It basically acts as a description of your website
when someone searches 'Workout Tracker' on the browser.

Example in search results:
Workout Tracker
Track workouts, sets, and reps easily.
www.example.com

4- Author

<meta name="author" content="Your Name">
Indicates who created the page.

5 - Keywords
<meta name="keywords" content="workout, fitness, tracker">
This is allows the use of keywords to improve search results for your website.




3- Linking css
This is how your HTML connects to your stylesheet.
Example folder structure you asked about earlier:

project
   index.html
   css/
       styles.css

Inside <head>:
<link rel="stylesheet" href="css/styles.css">

This loads your styling.


4 -Linking JavaScript

You can also connect JavaScript files.
Example:
project
   index.html
   js/
       script.js

This is how you implement it: 

<script src="js/script.js"></script>
However, most developers put scripts at the bottom of <body> so the page loads faster.



5 -                                                                                   Favicon (small tab icon)
This is the tiny icon in the browser tab.
Example: 
<link rel="icon" href="images/favicon.ico">

What does rel mean:
<link rel="something" href="file">

Essentially: <link
relationship = "what this file is"
href = "where the file is located"
>
 
Main ones to know: 
<link rel="stylesheet" href="css/styles.css">
<link rel="icon" href="images/favicon.ico">


THESE ELEMENTS COVER 90% OF THE HEAD FOR BEGINNER PROJECTS.
