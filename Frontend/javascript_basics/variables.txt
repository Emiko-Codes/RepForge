3. Variables

A variable stores a value.

let exerciseName = "Bench Press";
let sets = 3;
let completed = false;
Important keywords
let

Use when the value might change.

let reps = 8;
reps = 10;
const

Use when you do not plan to reassign the variable.

const appName = "Workout Tracker";

This does not always mean the inside cannot change for arrays/objects. It means the variable itself cannot point to a new value.

var

Older way. Avoid it as a beginner unless your teacher specifically uses it.
